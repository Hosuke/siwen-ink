孔子

c.551-479 BCE · 儒家至聖，稱閔子騫之言必中

別稱：仲尼、孔丘、尼父、夫子、孔夫子

所見（40 條）

  • 孔子 — 儒家之聖人，萬世師表，其言行見於《論語》諸經。
  • 楚聘孔子 — 楚國欲聘孔子，陳蔡大夫圍孔子於野。
  • 仲尼答三公問政 — 孔子因三君所遇之異，一一作答，以明政在因時制宜。
  • 仲尼知靈寶 — 仲尼識得紫文金簡之書，乃知夏禹不死之實。
  • 晏子不對 — 晏子面對齊景公屢問孔子之事，始終不予回答，揭示其對孔子之負面評價。
  • 仲尼不見晏子 — 晏子聞仲尼疑己，喻以君子獨立不慚，仲尼遂謝焉。
  • 仲尼行一節 — 晏子言仲尼處君子中不及舜，以其行一節故。
  • 勿憂孔子相魯 — 晏子獻策以鄰國聖人為憂，設計使孔子去魯。
  • 佛肸畔召孔子 — 佛肸以中牟畔，召孔子，孔子欲往。
  • 孔子遂行 — 孔子因魯國怠政而去魯周遊。
  • 季孫讓仲尼 — 孔子假人主之術蚤禁未形；子路不得行私惠，而害不得生
  • 蒲人止孔子 — 蒲地人阻止孔子去衞。
  • 鴟夷子皮 — 墨子記載孔子遣子貢至齊，樹鴟夷子皮於田常之門，欲亂其國之事。
  • 仲尼異楚人於所謂人 — 孔子異楚王「楚人得弓」之說，廣以為「人得之」，公孫龍據此喻白馬非馬之說不悖。
  • 公山不狃召孔子 — 公山不狃以費畔季氏，召孔子。
  • 孔丘論大骨
  • 孔子去陳 — 孔子因晉楚爭陳而去。
  • 孔子哭子路於中庭 — 夫子哭子路，進使者問故，既聞醢之遂命覆醢
  • 孔子適衞主顏濁鄒 — 孔子至衞國，住於顏濁鄒之家。
  • 孔子適陳 — 孔子遊陳，陳湣公六年之事；後陳亡，孔子亦卒。
  • 盛服見孔子 — 子路盛服見孔子，孔子以江流為喻，戒其衣服盛則天下孰肯諫。
  • 陽虎絀孔子 — 陽虎阻止孔子參加季氏饗士之禮。
  • 五百歲而有孔子 — 先人言周公卒五百歲而有孔子，孔子卒後至於今又五百歲，當有能紹明世者。
  • 仲尼欲封 — 晏子諫景公，弗封仲尼於齊。
  • 匡人拘孔子 — 孔子被困匡地，以天意自寬。
  • 孔子不言舜冠 — 孔子不言舜冠，以古王者務德好生，不尚冠冕之末。
  • 孔子之仕 — 孟子記孔子出處之節，以見聖人行道有時，去魯遲遲，仕魯獵較，皆有其義。
  • 孔子以六尺之杖 — 孔子持杖以問遠方來者之親疏，喻貴賤之等、尊卑之義。
  • 孔子射於矍相之圃
  • 孔子未喻孝悌忠順之道 — 孔子論舜見瞽瞍，不知孝悌忠順之正道，乃謬論也。
  • 孔子論子西 — 直於行者曲於欲，孔子知子西之不免。
  • 有若立為師 — 記弟子思慕孔子，立有若為師之事。
  • 郰人輓父之母誨孔子父墓 — 郰人告知孔子其父墓所在，使其得合葬。
  • 野合而生孔子 — 記孔子父母非正式結合而生的傳說。
  • 仲尼非學仙之人
  • 仲尼革容于欹器 — 孔子見欹器而改容，深悟中庸之道。
  • 孔子世家 — 孔子生平事跡的總述。
  • 厄於陳蔡 — 孔子在陳蔡之間被困絕糧。
  • 孔子年六十 — 孔子年六十，魯哀公三年。
  • 孔子擊磬 — 孔子擊磬，有荷蕢者過門而論。
