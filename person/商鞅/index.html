商鞅

c.390-338 BCE · 戰國時法家，佐秦孝公變法

別稱：公孫鞅、衛鞅、商君

觀正傳 →

所見（40 條）

  • 商君車裂 — 商鞅行法於秦，孝公薨而身被車裂，以新法不便於貴戚也。
  • 商君教秦孝公 — 商鞅教孝公行連坐、焚詩書、明法令、禁游宦之法，秦以富強。
  • 枝解吳起而車裂商君 — 吳起、商鞅皆有大功於國而皆以刑死，以大臣苦法、細民惡治也。
  • 商君相秦十年 — 商鞅執政秦國十年，國富兵強
  • 商鞅 — 戰國法家，秦孝公用以變法
  • 刑九賞一 — 刑多賞少，以刑為主
  • 士自行不可不審 — 公孫鞅欺公子卬以取魏，終不容於秦，亦不見容於魏。
  • 農戰 — 農業與戰爭乃國之根本
  • 二子之言已當 — 吳起、商鞅之言皆合時宜，其法皆效，而其人皆不得其死。
  • 以刑去刑 — 峻刑以止刑，達於無刑
  • 說民 — 以法馭民、勝其政之道
  • 以賞禁以刑勸 — 王者以賞禁、以刑勸，求過不求善，藉刑以去刑
  • 任地 — 分田數小，墾草務開，以地利致民死
  • 六淫四難 — 民從六淫則國弱，行四難則兵彊
  • 刑賞斷於民心 — 王者刑賞斷於民心，器用斷於家
  • 前刑而法 — 效於古者先德而治，效於今者前刑而法
  • 匿罪之罰重而告姦之賞厚 — 商君行法，匿罪者誅、告姦者賞，此使天下必為己視聽之道。
  • 善民與姦民 — 以善民治則亂，以姦民治則強
  • 度取稱權 — 民之性度而取長、稱而取重、權而索利
  • 重賞輕刑 — 厚賞以勸功，輕刑以息爭
  • 封於商 — 秦封商鞅於商十五邑
  • 聖賢遇暴 — 翼侯炙，鬼侯腊，比干剖心，梅伯醢，夷吾束縛，吳起枝解，孫子臏脚，商君車裂。皆世之仁賢忠良有道術之士，不幸而遇悖亂闇惑之主，終死於非命。聖賢不能逃死亡避戮辱，非才之罪，患在說之難也。
  • 商韓六蝨五蠹 — 商鞅、韓非之學，猶六蝨五蠹。
  • 大良造 — 商鞅之官名，總掌國政
  • 定分 — 名分定則姦偽不生，法令者民之命為治之本
  • 御盜 — 此篇已亡，内容無考
  • 耕戰
  • 賞罰
  • 辯慧亂之贊 — 巧辯慧黠，反為亂政之助
  • 上賢廢而貴貴立 — 上世親親愛私，中世上賢說仁，下世貴貴尊官
  • 五民 — 談說、處士、勇士、技藝、商賈五者，加於國用則田荒而兵弱
  • 以法去法者強 — 用法破法以成新治，國乃強
  • 作一 — 民非一則無以致欲，作一則力摶而彊
  • 作壹 — 專心農戰，歸於一途
  • 使商無得糴 — 禁商收購，使商不得糴而農不得糶
  • 使民無得擅徙 — 禁民擅移，居止有定
  • 修權 — 修權者，法、信、權三者是也。立法明分，秉權獨斷，民信賞罰，則治且威。
  • 兵守 — 四戰之國務在守戰，守城以死人之力與客生力戰，且慎使三軍無相過。
  • 刑人無國位 — 刑人有列則君子下其位，戮人無官任
  • 刑用於將過 — 王者刑用於將過則大邪不生，賞施於告姦則細過不失
