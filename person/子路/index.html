子路

c.542-480 BCE · 孔子弟子，子路之字

別稱：仲由、季路

觀正傳 →

所見（40 條）

  • 子路結纓而死 — 蒯聵作亂，子路救孔悝，不敵而死，正冠而死，孔子聞亂而傷之。
  • 子路
  • 仲由染以德教 — 仲由恃其自然，尼父染以德教，遂成賢哲。
  • 孔子哭子路於中庭 — 夫子哭子路，進使者問故，既聞醢之遂命覆醢
  • 葉公問孔子於子路 — 葉公向子路問孔子為人。
  • 子路揜雉 — 子路揜取雉兔，已而復釋之，非不知取也，乃知其故而不為。
  • 季孫讓仲尼 — 孔子假人主之術蚤禁未形；子路不得行私惠，而害不得生
  • 子羔為宰 — 子路使子羔為費宰，夫子以為賊夫人之子。
  • 閔子侍側 — 閔子、子路、冉有、子貢，各有氣象，夫子樂之。
  • 片言可以折獄 — 言子路果決，明斷獄讼也。
  • 知者若何仁者若何 — 孔子三問智仁之義，子路、子貢、顏淵各答，而有士、士君子、明君子之別。
  • 侍坐言志 — 孔門四子侍坐，各言其志，夫子深許曾皙之沂浴。
  • 升堂入室 — 學道由淺入深，如入門升堂以入於室也。
  • 厄於陳蔡 — 孔子在陳蔡之間被困絕糧。
  • 曲要磬折 — 孔子見漁父曲要磬折言拜而應，子路以為太敬，孔子以為禮賢之道。
  • 由也果 — 仲由從政之才
  • 盛服見孔子 — 子路盛服見孔子，孔子以江流為喻，戒其衣服盛則天下孰肯諫。
  • 見衞夫人南子 — 孔子見衞靈公夫人南子，子路不說。
  • 知德者鮮矣 — 謂通曉德行之人寡少。
  • 長沮桀溺耦耕 — 孔子過長沮、桀溺耦耕之地，問津。
  • 丘之禱久矣 — 聖人存心於平素。
  • 事人與事鬼 — 未能事人，焉能事鬼；未知生，焉知死。
  • 佛肸畔召孔子 — 佛肸以中牟畔，召孔子，孔子欲往。
  • 受業通者七十有七人 — 記孔子受業通達之弟子凡七十七人，別為四科。
  • 君子義以為上 — 君子尚義不尚勇，勇而無義則為亂，小人亦然。
  • 大臣具臣 — 以道事君，不可則止，是之謂大臣；具臣則不然。
  • 孔子 — 儒家之聖人，萬世師表，其言行見於《論語》諸經。
  • 居是邑不非其大夫 — 禮，居是邑不非其大夫。夫子不知，非不知，乃知而不言。
  • 聞斯行之 — 聞義而行，當視人之稟性進退，不可一概而論。
  • 荷蓧丈人 — 孔子遇荷蓧丈人，丈人譏孔子不勤四體。
  • 衣酤酒不問
  • 見南子 — 聖人應變而矢誓自明
  • 一以貫之
  • 下人不精不得其真 — 不能下人則不精，不精則不得其真，長傷其身。
  • 下愚之狂惑 — 效忠赴死不察禍福，雖烈而非上智之所取。
  • 以法去法者強 — 用法破法以成新治，國乃強
  • 修身得名 — 入而行不脩則身之罪，出而名不章則友之過。學者入則篤行，出則友賢。
  • 公山不狃召孔子 — 公山不狃以費畔季氏，召孔子。
  • 六言六蔽 — 好仁、好知、好信、好直、好勇、好剛，不學則各有其蔽。
