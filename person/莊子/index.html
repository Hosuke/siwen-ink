莊子

別稱：莊周

所見（40 條）

  • 莊周拒相 — 楚威王聞莊周賢，欲以相位迎之，莊周以郊祭犧牛為喻，辭而不仕。
  • 莊子將死 — 天地為棺槨，萬物為齎送
  • 甯莊子言於衛君 — 甯莊子告衛文公當禮重耳，晉將昌。
  • 虎精之鬼名健莊子 — 虎精之鬼名健莊子。
  • 說劍 — 莊子以劍喻政，勸趙文王止好鬥之習。
  • 神龜曳尾 — 楚王欲以相位累莊子，莊子以神龜為喻，寧生而曳尾塗中，不願死而留骨廟堂。喻軒冕祿位不如自然之樂。
  • 至仁無親 — 莊子以為至仁超乎孝悌，不涉親疏之恩。
  • 鯈魚出游從容 — 莊周與惠子濠梁之辯，「子非魚」之問，「請循其本」之答。喻認知相對，而樂在會心。
  • 虎狼仁也 — 莊子以父子相親釋仁，見虎狼亦有仁性。
  • 鮒魚轍中 — 莊周貸粟，而寓言涸轍之鮒，以諷遠水難活近渴。
  • 鼓盆而歌 — 莊子妻死，箕踞鼓盆而歌，以為生死如四時行焉。
  • 秋水 — 《莊子》外篇第十七，以河伯北海若之問答，論大小、盈虛、貴賤之相對，通於道而不執名言。
  • 馬蹄 — 莊子以馬喻人，刺伯樂治馬、聖人治世之過。
  • 髑髏見夢 — 莊子見髑髏，夢聞死之樂，蓋生死之論也。
  • 君子之道 — 莊子所述君子之行，無飢寒之患、無劫奪之憂
  • 道在屎溺 — 道無所不在，雖至穢之物亦寓其中。
  • 無何有之宮 — 無何有之宮，遊心於道之虛境。
  • 鵷鶵過焉 — 鵷鶵非梧桐不止、非練實不食、過南海而北海；鴟得腐鼠而嚇之。喻以小人之腑度君子之志。
  • 不得已與時中 — 莊子「不得已」與《中庸》「時中」之比較，闡明二者皆順勢應物、去人為私之至道。
  • 不龜手之藥 — 同一藥也，或用以洴澼絖，或用以裂地封侯，用之異也。
  • 以好惡內傷其身 — 情起於好惡，好惡妄作，則內傷其身。
  • 大樗 — 大樹無用，不夭斤斧，逍遙寢臥其下，乃無用之用。
  • 安時處順 — 得者時也，失者順也，安時而處順，哀樂不能入，此古之所謂縣解。
  • 市南宜僚 — 聖人隱於市朝，心與世違而不屑與俱。
  • 庶人之劍 — 匹夫之勇，上斬頸領，下決肝肺，無益國事。
  • 德充符 — 形骸之殘，不害德之充；德充於內，物不能離。
  • 物固相累二類相召 — 萬物相制相因，利與害迭相承轉，實一理也。
  • 至人用心 — 至人知命不惑，不以得失為憾。
  • 亡羊而喻 — 臧者讀書，穀者博塞，事業不同，亡羊則均。以喻殉名殉利各異，而失性同歸。
  • 以敬孝易以愛孝難 — 孝有高下層次，由敬及忘，漸進於道。
  • 伯夷盜跖同道 — 伯夷死名，盜跖死利，所殉不同，而殘生傷性均也。
  • 儒以詩禮發冢 — 儒者表面誦《詩》《禮》，而行盜墓之事，以諷儒學之偽。
  • 入其俗從其令 — 君子遊於異地，當從其俗、循其令，不以己意加之。
  • 務光 — 夏時人，耳長七寸，好琴，服蒲韭根。辭湯天下讓，負石自沉寥水，後復見，投河浮山，遊尚父山。
  • 匠石運斤 — 巧匠運斤成風，無堊則無所用其巧；知己既亡，巧無所施。
  • 千金之珠在驪龍頷下 — 厚利必伏大患，僥倖難恃
  • 受才乎大本 — 才受於大道根本，復其靈明以生，是聖人之所以貴也。
  • 天子之劍 — 以天下為劍，上決浮雲，下絕地紀。
  • 天鬻 — 天以道養人，如鬻物然；受食於天，不假人力。
  • 孝固不足以言之 — 至仁之境，尚矣，孝不足以言。
