第四十七章 安民

原文

不上賢 使民不爭 不貴難得之貨 使民不為盜 不見可欲 使民不亂 是以𦔻人之治也 虚亓心 實亓腹 弱亓志 強其骨 恒使民无知无欲也 使夫知不敢弗為而巳 則无不治矣

對校

不尚賢，使民不爭；不貴難得之貨，使民不為盜；不見可欲，使民心不亂。 : 是以聖人之治，虛其心，實其腹， : 弱其志，強其骨。 : 常使民無知無欲。 : 使夫智者不敢為也。 : 為無為，則無不治。

甲乙本校記

本章首句、「使民不亂」及「強其骨」「恒使民无知无欲也」四句據甲本，餘甲本殘泐，據乙本補；字從《集成》（2014）括號外原字。

  • 不上賢：甲乙同，「上」讀為「尚」；王弼本作「不尚賢」。
  • 使民不爭　不貴難得之貨　使民不為盜　不見可欲：甲本殘泐，唯存「民不為」三字及「不見」之「不」，「不」字《集成》直接釋出；四句皆據乙本補。
  • 使民不亂：從甲本，乙本同。甲本「使」字《集成》直接釋出。「亂」字甲本左半已殘，僅存乚形，乙本作省形之「乿」，《集成》皆讀為「亂」。王弼本作「使民心不亂」，帛書二本皆無「心」字。
  • 是以𦔻人之治也：甲本唯存「是以聲人之」，下殘，據乙本。甲作「聲人」，乙作⿰耳口之「𦔻人」，皆讀為「聖人」。王弼本作「是以聖人之治」，無「也」。
  • 虛亓心　實亓腹　弱亓志：甲本殘，據乙本；乙本作「亓」，讀為「其」。
  • 強其骨：從甲本；乙本作「強亓骨」。
  • 恒使民无知无欲也：甲乙同；王弼本作「常使民無知無欲」，無「也」。
  • 使夫知不敢弗為而巳：據乙本，「巳」讀為「已」。甲本作「使夫□不敢□為□□」；其「不敢」「為」三字，原釋文皆在所補缺文中，《集成》據新綴入之兩小殘片直接釋出。王弼本作「使夫智者不敢為也。為無為」，帛書二本皆無「者」字，作「弗為而巳」，亦無「為無為」三字。（《集成》肆·頁45·注17）
  • 則无不治矣：甲本殘，據乙本。王弼本作「則無不治」，無「矣」。

注疏

杳眇曰：

道經此章，論治世之要，其要在絕上之所尚，還斯民於渾噩。民之初，无知无欲，湛然純樸，與道為一。及其後也，上有好者，下必甚焉。尚賢則民爭，貴貨則民盜，見欲則民心搖。三者既熾，天下紛然矣。

是以聖人之治，先絕其源。心者欲之府，虛之則嗜欲不入；腹者生之本，實之則飢寒不迫；志者求之未也，弱之則不貪；骨者體之充也，強之則有力。四者並施，民自然返乎朴素。

今以帛書校之，異同有三。其一，帛書云「不上賢」，王弼本云「不尚賢」——尚也、上也，皆尊崇之謂。賢名一設，則民趨之若騖，競名位而爭利祿。此即不上賢、使民不爭之義也。其二，帛書作「使民不亂」，王弼本增「心」字作「民心不亂」——言各有當，義則相通。可欲在前，則欲心必動；欲[[使心不亂]]，聖人藏美物、絕外界之誘，此治道之要也。其三，二本末句差異尤顯。帛書云「使夫知不敢，弗為而巳」，王弼本則云「使夫智者不敢為也。為無為，則無不治」。「恒使民无知无欲」者，此「知」非愚昧之知，乃計較分別之知；「欲」非無需之欲，乃貪取之欲。使民保其本樸，非使民無智也。「弗為」者，不妄為也，非有為，亦非徒「為無為」。及其不為，萬物自化，此之謂至治。

上無為而民自化，治道之要，在不擾耳。儒家言「克己」「無欲則剛」，與此實相通焉。嗚呼！失此道者，崇賢以激爭，貴貨以啟盜，見欲以誘亂——源不清而求流之澄，源淆而求治，其可得乎。
