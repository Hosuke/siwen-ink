第二十四章 處下

原文

大邦者下流也 天下之牝 天下之郊也

牝恆以靜朕牡為其靜也故宜為下也

故大國以下□國 則取小邦 小邦以下大邦 則取於大邦 故或下以取 或下而取

故大國者不過欲并畜人 小邦者不過欲入事人

夫皆得亓欲 則大者宜為下

對校

大國者下流， : 天下之交。 : 天下之牝， : 牝常以靜勝牡，以靜為下。 : 故大國以下小國， : 則取小國； : 小國以下大國，則取大國。 : 故或下以取，或下而取。 : 大國不過欲兼畜人，小國不過欲入事人。夫兩者各得其所欲，大者宜為下。 :

甲乙本校記

本章帛書原文大體據甲本；「牝恆以靜」「故大國以下□國」「故大國者不過欲并畜人」「則大者宜為下」四句甲本殘，據乙本補，故文中「邦」「國」雜出；字從《集成》（2014）括號外原字。

  • 大邦者下流也：從甲本。乙本「邦」皆作「國」，蓋避漢高祖諱，下同。乙本「流」字殘；「者」字原釋文作補文，《集成》據襯頁反印文直接釋出。甲本「牝」字右旁多一筆，乃訛變之形，《集成》釋字不變。（《集成》肆·頁32·注122；頁202·注108）
  • 天下之牝　天下之郊也：從甲本；乙本作「天下之牝也，天下之交也」。乙本、北大本及多數傳本作「交」，遂州本、敦煌諸本與成玄英《義疏》本亦作「郊」。《集成》從原整理者括注「交」，並從高明說，以「天下之郊（交）也，牝恆以靜勝牡」連讀，謂以雌雄交配為喻；然以借「郊」為「交」古書無例，不排除甲本以「大邦者下流也，天下之牝，天下之郊也」為一句。乙本「下」「也」及「天下之」諸字原作補文，《集成》據反印文直接釋出。王弼本二句互倒，作「天下之交，天下之牝」。（《集成》肆·頁32·注123；頁202·注109、注110）
  • 牝恆以靜朕牡為其靜也故宜為下也：甲本作「牝恒以靚勝牡，為亓靚【也，故】宜為下」，「也故」二字殘，今從乙本。甲用「靚」、「勝」，乙用「靜」、「朕」，「朕」讀為「勝」。王弼本作「牝常以靜勝牡，以靜為下」；原注謂通行本作「以靜為下」，北大本作「以其靜也，故為下」，傅奕本作「以其靖，故為下也」，二帛書本較近之。（《集成》肆·頁202·注111）
  • 故大國以下□國：二本皆殘。乙本作「故大國以下□國」，「小」字殘；甲本作「大邦以下小【邦】」，無「故」字而存「小」字，「以」字《集成》直接釋出。今從乙本，甲本可補其闕為「小」。
  • 則取小邦　小邦以下大邦：甲本作「則取小﹦邦﹦以下大邦」，「小邦」二字下有重文號，讀為「則取小邦，小邦以下大邦」；乙本同而作「國」。
  • 則取於大邦：甲乙同（乙作「國」）；王弼本無「於」字，作「則取大國」。
  • 故或下以取　或下而取：從甲本；乙本「或」字殘，其「以取」二字原釋文分補於上下兩截，《集成》據反印文於23上直接釋出。（《集成》肆·頁203·注112）
  • 故大國者不過欲并畜人：甲本首字殘，作「□大邦者不過欲兼畜人」；今從乙本。甲作「兼」，乙作「并」，王弼本作「兼」，無「故」「者」二字。乙本「過」字原作補文，《集成》據反印文直接釋出。（《集成》肆·頁203·注113）
  • 小邦者不過欲入事人：從甲本；乙本作「小國不【過】欲入事人」，無「者」字，「過」字殘，《集成》作補文。
  • 夫皆得亓欲：甲乙同；乙本「皆得」二字原作補文，《集成》據反印文直接釋出。王弼本作「夫兩者各得其所欲」。（《集成》肆·頁203·注114）
  • 則大者宜為下：甲本唯存「為下」二字，今從乙本。《集成》於甲本補作「【故大邦者宜】為下」，凡五字，與乙本不同，補文出整理者推定。王弼本作「大者宜為下」，無「則」字。

注疏

杳眇曰：

老子此章以水喻邦交，明大邦小邦相處之道，其要在下而已。水之性趨下而不爭，江河東流以歸海，谿谷奔赴以趨壑。大邦若天下之下流，則萬邦歸之者，豈偶然哉。

天下之牝，天下之交，牝者雌也，靜而能勝牡。大邦如牝，非以力陵小邦，乃以靜召之，以下取之。牝恆以靚勝牡，帛書甲本作「靚」，即清靜之本字，乙本與王弼本作「靜」，字殊而義同。靜者非怯懦也，靜而能受，以下勝上，道之自然也。大國謙下，則小國自附，此之謂與。

大邦以下小邦則取小邦，小邦以下大邦則取於大邦，彼此各得其欲。帛書云「故或下以取，或下而取」，以取者，大邦主動兼畜人也；而取者，小邦被動入事人也。句法之辨，正見古人措辭之密。

末云夫皆得欲，大者宜為下。兩得其欲，責在大者。何也？上者居高而下之難，下者本卑而下之易。大邦本高，能下乃為可貴；小邦本下，下之不足為異也。故曰大者宜為下，此非聖人過謙，乃知道者深知所處也。水善利萬物而有靜，處眾人之所惡，千古治道之鑰其在茲乎。
