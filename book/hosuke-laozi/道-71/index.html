第七十一章 曳明

原文

善行者无勶迹 善言者无瑕適 善數者不以檮𥮥 善閉者无𫔢籥而不可啟也 善結者无𦄿約而不可解也 是以聲人恒善㤹人 而无棄人 物无棄財是胃忡明

故善人 善人之師 不善人 善人之齎也 不貴其師 不愛其齎唯知乎大眯 是胃眇要

對校

善行無轍迹， : 善言無瑕讁； : 善數不用籌策； : 善閉無關楗而不可開，善結無繩約而不可解。 : 是以聖人常善救人，故無棄人； : 常善救物，故無棄物，是謂襲明。故善人者，不善人之師； : 不善人者，善人之資。 : 不貴其師，不愛其資，雖智大迷， : 是謂要妙。

甲乙本校記

本章帛書原文據甲本，甲殘之「善言者无瑕適」「善結者无𦄿約而不可解也」「故善人　善人之師」據乙本補；字從《集成》（2014）括號外原字。

  • 善行者无勶迹：從甲本，「勶」讀為「轍」；乙本作「善行者无達迹」。王弼本作「善行無轍迹」，無「者」字，下四句同。
  • 善言者无瑕適：甲本「善」字殘，據乙本。「適」讀為「謫」。王弼本作「善言無瑕讁」。
  • 善數者不以檮𥮥：從甲本。「檮」讀為「籌」；「𥮥」上从竹、下从析，圖版、1980 釋文、高明實錄同，讀為「策」。乙本作「善數者不用檮𫁶」，「以」作「用」；其讀「策」之字，1980 釋文作上竹下尺，《集成》改隸定作上竹下片，謂所从「片」形即「析」之表意初文。王弼本作「善數不用籌策」。（《集成》肆·頁209·注42）
  • 善閉者无𫔢籥而不可啟也：從甲本。「𫔢」門中一豎貫串，讀為「關」，「籥」讀為「闔」；乙本作「關籥」，其「善」下一字原誤抄為「數」，已圈去作廢。王弼本作「善閉無關楗而不可開」。（《集成》肆·頁210·注43）
  • 善結者无𦄿約而不可解也：甲本「无纆」二字殘，據乙本。乙本「纆」字原作从糸从黑之形，為「纆」之異體。王弼本作「善結無繩約而不可解」。（《集成》肆·頁52·注106）
  • 是以聲人恒善㤹人：從甲本，「聲」讀為「聖」；乙本作「是以𦔻人恆善㤹人」。「㤹」讀為「救」；甲本此字右从求，左下曲筆心、辶兩可，1980 釋文與高明實錄皆釋从忄。王弼本作「是以聖人常善救人」。
  • 物无棄財是胃忡明：從甲本。甲本作「忡」，《集成》以為从忄从曳之字之誤，以〈〉正之；乙本作「曳」，《集成》亦讀為此从忄从曳之字。王弼本作「常善救物，故無棄物，是謂襲明」，多「常善救物」一句，「財」作「物」，「曳」作「襲」。
  • 故善人　善人之師：甲本「故善」下有重文號，「人」字及其重文號殘，《集成》補作「故善﹦【人﹦】」；今據乙本「故善﹦人﹦之師」，讀作「故善人，善人之師」。王弼本作「故善人者，不善人之師」，帛書二本皆無「不」字，義與王弼本異。
  • 善人之齎也：從甲本，「齎」讀為「資」；乙本作「善人之資也」。王弼本作「善人之資」。
  • 不愛其齎唯知乎大眯：從甲本。甲本「愛」字原作「㤅」之異寫，《集成》以〈愛〉正之；「唯」讀為「雖」，「知」讀為「智」，「眯」讀為「迷」。乙本作「不愛亓資雖知乎大迷」。王弼本作「不愛其資，雖智大迷」。
  • 是胃眇要：甲乙同；王弼本作「是謂要妙」，二字互倒，「眇」作「妙」。

注疏

杳眇曰：

此章之旨，在明聖人之善無方，而道之要妙於「不用」二字。帛書與王弼本之異，非止字句之殊，乃義理淺深之別也。

夫五善之目，行、言、數、閉、結是也。「善行者无勶迹」（勶讀為轍）者，功成而不居也；「善言者无瑕適」者，言出於天理之自然，無隙可尋也；「善數者不以檮𥮥」者，天理具於一心，無待外物也；「善閉者无𫔢籥」者，因無隙而不設扃鍵也；「善結者无𦄿約」（乙本；𦄿即纆）者，以道心相維，莫能離散也。五者異用，同歸於「不用」——不用者，自然而然，不恃外物之謂也。

獨異者，帛書乙本作「曳明」（甲本作「忡」，《集成》以為从忄从曳之「㥏」之誤），王弼作「襲明」。原注引《說文》「㥏，習也」、《蒼頡篇》「㥏，明也」，謂襲、習古通用，則曳（㥏）明即襲明，字異而音義相通。杳眇竊謂乙本「曳」字或可如字讀之：曳者，引挽之也，聖人主動導引萬物，使各歸其明；《說文》云「曳，臾曳也」，有導而前之義。「襲」從衣，承而加之也，聖人稟受於道，以明照臨天下。如字讀之，帛書言「曳」，是聖人躬親引道之功，主動用事者也；王弼言「襲」，是聖人稟道受明，無為以化之也。二義相足，而「曳明」尤見聖人之弘願深心。又「物无棄財」與「故無棄物」相較，帛書以「財」代王本之「物」——不唯人無可棄，物與財亦無可棄，此聖人之所以為大也。

至若「故善人，善人之師；不善人，善人之齎也」（齎讀為資），王弼作「故善人者，不善人之師」，帛書二本皆無「不」字，義與通行本異：善人為善人之師，則師道相承於善者之間；不善人則為善人之資。師資相待而成：貴師則善日進，愛資則過日寡。然老子更深其義，曰「不貴其師，不愛其齎，唯知乎大眯，是胃眇要」——唯讀為雖，眯者迷也，眇者微也，要者樞紐也。貴師而驕己，愛資而棄人，皆未至乎[[玄同]]之境。惟聖人不以己為師、不以彼為資，師資兩忘而道全，此之謂眇要。

帛書作「眇要」，王弼作「要妙」——眇者深微之義，妙者精微之義，義雖相通，而「眇要」兼深與切，直指道之不可名之至處。所謂「古之善為道者，微眇玄達」，即此境也。

嗟乎！五善之用，在乎不用；不用之妙，在乎无為；无為之極，在乎曳引天下皆歸於明。聖人曳物使之自明，非以己明加於物，故物自歸道而聖人無功焉。世人皆知善之為善，而不知不善者亦善之資——此玄同之理，上善治水之所以善利萬物而有靜者也。學者苟於此玩索而有得，則無棄人、無棄物之德，可坐而致矣。
