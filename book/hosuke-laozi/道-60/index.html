第六十章 歸根

原文

至虛極也 守情表也萬物旁作 吾以觀其復也天物雲雲 各復歸於亓根 曰靜 靜是胃復命 復命常也 知常明也

不知常芇 芇作兇知常容 容乃公 公乃王 王乃天 天乃道 道乃 沕身不怠

對校

致虛極，守靜篤。 : 萬物並作，吾以觀復。 : 夫物芸芸，各復歸其根。歸根曰靜，是謂復命。復命曰常， : 知常曰明。不知常，妄作凶。 : 知常容， : 容乃公， : 公乃全， : 全乃天， : 天乃道， : 道乃久， : 沒身不殆。 :

甲乙本校記

本章前半與「復命常也」以下多據甲本；「各復歸於亓根」「曰靜」「靜是胃復命」及「道乃」甲本殘，據乙本補；字從《集成》（2014）括號外原字。

  • 至虛極也：甲乙同；王弼本作「致虛極」，無「也」。
  • 守情表也：從甲本，《集成》讀「情」為「靜」；乙本作「守靜督也」，其「靜」字印本左爭右青，無碼位，今錄「靜」。王弼本作「守靜篤」。
  • 萬物旁作　吾以觀其復也：甲乙同，「旁」讀為「並」；乙本「其」作「亓」。王弼本作「萬物並作，吾以觀復」，無「其」「也」。
  • 天物雲雲：從甲本，甲作「雲﹦」。乙本作从示从云之字，原整理者以从示、从鬼義通，視為「魂」之異體；高明書影作「秐秐」。王弼本作「夫物芸芸」。（《集成》肆·頁49·注66）
  • 各復歸於亓根：據乙本；甲本作「各復歸於其」，「根」以下殘。王弼本作「各復歸其根」。
  • 曰靜　靜是胃復命：據乙本。甲本「根曰靜」三字殘，次行之首唯存「靜」之重文號。王弼本作「歸根曰靜」；乙本無「歸根」二字，原注以為脫文，《集成》以北大本亦無，甲本殘處以缺文字數推之亦當無，不從原注補。（《集成》肆·頁209·注25）
  • 復命常也：甲乙皆以重文號讀作「是胃復命，復命常也」。王弼本作「復命曰常」。
  • 知常明也：甲乙同；王弼本作「知常曰明」。
  • 不知常芇　芇作兇：從甲本，甲作「芇﹦」；乙本作「芒﹦」，《集成》讀為「妄妄」，「兇」乙本作「凶」。王弼本作「不知常，妄作凶」，「妄」字不重。
  • 公乃王　王乃天：從甲本；乙本「王」下重文號殘，「乃天」二字亦殘。甲乙皆作「王」，王弼本作「公乃全，全乃天」。
  • 天乃道　道乃　沕身不怠：甲本「乃道」下之重文號與「乃久」二字殘，《集成》補之，次作「沕身不怠」，讀為「沒身不殆」。乙本作「乃道﹦乃沒身不殆」，「沒」上脫「久」字，原注謂此脫，《集成》從而補之（作「乃〖久〗，沒身不殆」）。今「道乃」據乙本，乙本既脫「久」字，此句遂止於「乃」；「沕身不怠」從甲本，「沕」即乙本之「沒」。合而讀之，當作「道乃久，沒身不殆」，與王弼本同。（《集成》肆·頁209·注26）

注疏

此章以虛靜為歸根之功，以知常為復命之要，首尾相銜，渾然一體。

「至虛極也，守情表也」（甲本；乙本作「守靜督也」）——帛書與王弼本異者，「情表」與「靜篤」是也。《集成》讀情為靜；原注謂表或為誤字，督、表皆當讀為篤，則甲本與王弼「守靜篤」本同。杳眇竊謂甲本「情表」或可如字讀之：王弼分虛與靜為二，帛書以一「情表」統之，義更邃密。情者，感物之原；表者，萬化之迹。守情表者，非枯坐寂寥之謂，乃心感於物而不逐物生情、與萬象交而不為萬象所移之義。虛而至於極，則心之應物也，自然而不立我，自然而不生執，此「至虛極、守情表」之微旨也。

「萬物旁作，吾以觀其復也」——旁作者，萬物並起迭興也。帛書多一「其」字（甲本；乙本作「亓」），義尤明晰。聖人虛心澄觀，非觀萬物之起，乃觀其往而復返之機。起者千歧，歸者同轍；起者出於一源，歸者返於一源。觀其復者，非有為之觀，乃至虛守情之餘，萬象自映於心鏡之中，如鏡中花、水中月，不將不迎，來無所黏、去無所滯。

「天物雲雲，各復歸於亓根」——帛書作「天物」，王弼作「夫物」。天物者，天所以生之萬物也，取義更寬。天有好生之德，物稟之而生、生而復歸，歸者歸於天所與之命，非歸於有形之根。雲雲者，萬象之繽紛也；歸根者，萬殊之一本也。知此則知聖人之心，應萬物而不累於萬物。

「曰靜，靜是胃復命」（乙本；無「歸根」二字，原注以為脫文，《集成》以北大本亦無而不補）——靜非死寂之靜，乃歸根之時、返本之候。命者，天之所以賦物者；復命者，物之還其本初之性也。《周易》謂「窮理盡性以至於命」，歸根之謂也。靜而後能復命，能復命而後謂之常——常者，不易之理也。

「知常容，容乃公，公乃王，王乃天，天乃道，道乃久，沒身不殆」（甲本「道乃久」殘，作「沕身不怠」，沕讀為沒，怠讀為殆；乙本脫「久」字，作「道乃沒身不殆」）——此六句者，進於道之階梯也，渾然一氣，無少間斷。知常則通達無蔽，通達故能容，能容故無私，無私則天下歸往而為王，王者與天合德，合天德者同道，道體無疆，故沒身不殆。獨異者，帛書「公乃王」，王弼本作「公乃全」。全者，完也；王者，往也。公而能往，其義與下文「王乃天」更相承接，邏輯尤密。公而為王，非私天下之謂，乃天下莫不歸往之謂也。知此則知老子之學，非隱約自守之學，乃與天地合德之學，與《[[中庸]]》所言「肫肫其仁，淵淵其淵」者，氣脈相通矣。

「不知常，芇芇作兇」——甲本作「芇﹦」，乙本作「芒﹦」，皆借為「妄妄」，形容妄動之貌，與王弼「妄」義同，而帛書疊之，其狀尤迫。不知常而妄作者，干造化之自然，逆陰陽之節序，取凶必矣。《[[孟子]]》曰「求其放心」，老子所謂知常者，亦求其本心之常然而已。放心則妄作，知常則安而行之，此吉凶之所以分也。

是章也，虛靜為歸根之本，知常為合道之基，由人道以躋天德，由天德以合道體，脩身治世，一以貫之。學者苟能至虛極而守情表，則歸根復命，不外是矣。
