第六十章 歸根

原文

至虛極也 守情表也 萬物旁作 吾以觀亓復也 天物雲雲 各復歸於亓根 曰靜 靜是謂復命 復命常也 知常明也

不知常 㠵㠵作兇 知常容 容乃公 公乃王 王乃天 天乃道 道乃久 歿身不殆

對校

致虛極，守靜篤。 : 萬物並作，吾以觀復。 : 夫物芸芸，各復歸其根。歸根曰靜，是謂復命。復命曰常， : 知常曰明。不知常，妄作凶。 : 知常容， : 容乃公， : 公乃全， : 全乃天， : 天乃道， : 道乃久， : 沒身不殆。 :

注疏

杳眇曰：

此章以虛靜為歸根之功，以知常為復命之要，首尾相銜，渾然一體。

「至虛極也，守情表也」——帛書與王弼本異者，「情表」與「靜篤」是也。王弼分虛與靜為二，帛書以一「情表」統之，義更邃密。情者，感物之原；表者，萬化之迹。守情表者，非枯坐寂寥之謂，乃心感於物而不逐物生情、與萬象交而不為萬象所移之義。虛而至於極，則心之應物也，自然而不立我，自然而不生執，此「至虛極、守情表」之微旨也。

「萬物旁作，吾以觀亓復也」——旁作者，萬物並起迭興也。帛書多一「亓」字，義尤明晰。聖人虛心澄觀，非觀萬物之起，乃觀其往而復返之機。起者千歧，歸者同轍；起者出於一源，歸者返於一源。觀其復者，非有為之觀，乃至虛守情之餘，萬象自映於心鏡之中，如鏡中花、水中月，不將不迎，來無所黏、去無所滯。

「天物雲雲，各復歸於亓根」——帛書作「天物」，王弼作「夫物」。天物者，天所以生之萬物也，取義更寬。天有好生之德，物稟之而生、生而復歸，歸者歸於天所與之命，非歸於有形之根。雲雲者，萬象之繽紛也；歸根者，萬殊之一本也。知此則知聖人之心，應萬物而不累於萬物。

「歸根曰靜，靜是謂復命」——靜非死寂之靜，乃歸根之時、返本之候。命者，天之所以賦物者；復命者，物之還其本初之性也。《周易》謂「窮理盡性以至於命」，歸根之謂也。靜而後能復命，能復命而後謂之常——常者，不易之理也。

「知常容，容乃公，公乃王，王乃天，天乃道，道乃久，歿身不殆」——此六句者，進於道之階梯也，渾然一氣，無少間斷。知常則通達無蔽，通達故能容，能容故無私，無私則天下歸往而為王，王者與天合德，合天德者同道，道體無疆，故歿身不殆。獨異者，帛書「公乃王」，王弼本作「公乃全」。全者，完也；王者，往也。公而能往，其義與下文「王乃天」更相承接，邏輯尤密。公而為王，非私天下之謂，乃天下莫不歸往之謂也。知此則知老子之學，非隱約自守之學，乃與天地合德之學，與《[[中庸]]》所言「肫肫其仁，淵淵其淵」者，氣脈相通矣。

「不知常，㠵㠵作兇」——㠵㠵者，帛書假借字，形容妄動之貌，與王弼「妄」義同。不知常而妄作者，干造化之自然，逆陰陽之節序，取凶必矣。《[[孟子]]》曰「求其放心」，老子所謂知常者，亦求其本心之常然而已。放心則妄作，知常則安而行之，此吉凶之所以分也。

是章也，虛靜為歸根之本，知常為合道之基，由人道以躋天德，由天德以合道體，脩身治世，一以貫之。學者苟能至虛極而守情表，則歸根復命，不外是矣。
