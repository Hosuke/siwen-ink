第六十九章 昆成

原文

有物昆成 先天地生

蕭呵漻呵獨立而不𪻞 可以為天地母 吾未知其名 字之曰道 吾強為之名曰大 大曰筮 筮曰遠 遠曰反

道大 天大 地大 王亦大 國中有四大 而王居一焉 人法地 地法天 天法道 道法自然

對校

有物混成，先天地生。 : 寂兮寥兮，獨立而不改， : 周行而不殆，可以為天下母。 : 吾不知其名， : 字之曰道， : 強為之名曰大。 : 大曰逝， : 逝曰遠，遠曰反。 : 故道大，天大，地大，王亦大。 : 域中有四大， : 而王居其一焉。 : 人法地，地法天，天法道，道法自然。 :

甲乙本校記

本章帛書原文據甲本，「蕭呵漻呵獨立而不𪻞」「大曰筮」「遠曰反」「道大」及末三句甲本殘，據乙本補；字從《集成》（2014）括號外原字。

  • 有物昆成：甲乙同，《集成》讀「昆」為「混」。王弼本作「有物混成」。
  • 蕭呵漻呵獨立而不𪻞：從乙本。甲本作「繡何繆何獨立□□□」，「何」讀為「呵」，「而不改」三字殘（甲本第140行末）。甲之「繡」「繆」、乙之「蕭」「漻」，《集成》皆讀為「寂」「寥」。乙本末字作⿰王亥之「𪻞」，讀為「改」；高明實錄作「孩」，圖版左旁實作王。王弼本作「寂兮寥兮，獨立而不改」，下有「周行而不殆」一句，帛書二本皆無。
  • 可以為天地母：甲乙同；王弼本作「可以為天下母」。
  • 吾未知其名：從甲本；乙本作「吾未知亓名也」，句末有「也」字。王弼本作「吾不知其名」。
  • 吾強為之名曰大：甲乙同；王弼本作「強為之名曰大」，無「吾」字。
  • 大曰筮：甲本「大」下重文號殘去，《集成》補之，今據乙本。「筮」讀為「逝」，王弼本作「大曰逝」。
  • 筮曰遠　遠曰反：「筮曰遠」從甲本；甲本「遠」字原在補文中，《集成》據新綴小殘片直接釋出，其下重文號已殘去，作補文處理。「遠曰反」甲本殘，據乙本，乙本「反」讀為「返」。（《集成》肆·頁52·注98）
  • 道大：甲本殘，據乙本。王弼本作「故道大」。
  • 王亦大　而王居一焉：甲乙原件皆作「王」，圖版、1980 釋文、高明實錄同；或錄作「人亦大」「而人居一焉」者，誤。王弼本作「王亦大」「而王居其一焉」。
  • 國中有四大：甲乙同，《集成》讀「國」為「域」；王弼本作「域中有四大」。
  • 地法天　天法道　道法自然：甲本「人法地」下重文號殘，唯存「法天﹦法」，餘殘，據乙本。乙本以重文號連讀，作「人法地﹦法天﹦法道﹦法自然」。

注疏

杳眇曰：

此章言道之體用最為完整，學者不可不察。

夫帛書云「有物昆成」，王弼本作「有物混成」。《集成》讀昆為混；杳眇竊謂或可如字讀之：昆者，渾淪之義，言道未剖之時，萬物一團而無間也。混則已涉於雜，昆則本然如是。有物昆成之義，所以明道先天地而生，渾然自存，非由湊泊。《大宗師》云「夫道有情有信，无為无形，自本自根，未有天地，自古以固存」，正此之謂。

次云「繡何繆何」（甲本，何讀為呵；乙本作「蕭呵漻呵」），王弼本作「寂兮寥兮」。《集成》讀繡、蕭為寂，繆、漻為寥，則帛王本同；若如字讀之，寂寥者，虛無之狀；繡繆者，糾纏之貌，二義相異，然皆所以言道不可以形名求也。繡如絲之互織，繆如繩之相縈，道之於天下，無所不貫，無所不入，錯綜周流，其用廣矣。

「字之曰道，吾強為之名曰大」，此聖人不得已而立言也。道經首章云「道可道也，非恒道也」，強以字名，強以大稱，非妄作也。凡名皆假，讀者當得意忘言可也。

「大曰筮，筮曰遠，遠曰反」，王弼本以「逝」代「筮」，作「大曰逝，逝曰遠，遠曰反」。《集成》讀筮為逝；如字讀之，筮者，推演占度之義；逝者，往也，亦通。蓋道之為大，必有所往，往而後遠，遠而後返，周流不殆，終則有始。《易》曰「無平不陂，無往不復」，理在此矣。

王弼本作「域中有四大，而王居其一焉」；帛書作「國中有四大，而王居一焉」，《集成》讀國為域，則與王弼同；如字讀之，義稍隘。域者無疆，國者有域，以道言之，域中為優。然四大之旨則一：道大，天大，地大，王亦大——帛書甲乙皆作「王」，與王弼本同。王者，人之代表也，人能參天地之大，唯以王為代表。

「人法地，地法天，天法道，道法自然」，此四法之序也。人法地，取其厚德无私；地法天，取其覆載无私；天法道，取其不宰有功；道法自然，自然者非自然界，乃「自然而然」之自性——道之所以然者也。連道亦有所法，是自然者道之道也。此章之眼，於是乎在。

道之在天下，大矣遠矣，彌綸宇宙，而要歸自然。聖人知返，百姓日用而不知，學者苟會此循環之理，則道生天地之旨，思過半矣。
