第六十九章 昆成

原文

有物昆成 先天地生

繡呵繆呵 獨立而不改 可以為天地母 吾未知亓名 字之曰道 吾強為之名曰大 大曰筮 筮曰遠 遠曰反

道大 天大 地大 人亦大 國中有四大 而王居一焉 人法地 地法天 天法道 道法自然

對校

有物混成，先天地生。 : 寂兮寥兮，獨立而不改， : 周行而不殆，可以為天下母。 : 吾不知其名， : 字之曰道， : 強為之名曰大。 : 大曰逝， : 逝曰遠，遠曰反。 : 故道大，天大，地大，王亦大。 : 域中有四大， : 而王居其一焉。 : 人法地，地法天，天法道，道法自然。 :

注疏

杳眇曰：

此章言道之體用最為完整，學者不可不察。

夫帛書云「有物昆成」，王弼本作「有物混成」。昆者，渾淪之義，言道未剖之時，萬物一團而無間也。混則已涉於雜，昆則本然如是。有物昆成之義，所以明道先天地而生，渾然自存，非由湊泊。《大宗師》云「夫道有情有信，無為无形，自本自根，未有天地，自古以固存」，正此之謂。

次云「繡呵繆呵」，王弼本作「寂兮寥兮」。寂寥者，虛無之狀；繡繆者，糾纏之貌，二義相異，然皆所以言道不可以形名求也。繡如絲之互織，繆如繩之相縈，道之於天下，無所不貫，無所不入，錯綜周流，其用廣矣。

「字之曰道，吾強為之名曰大」，此聖人不得已而立言也。道經首章云「道可道也，非恆道也」，強以字名，強以大稱，非妄作也。凡名皆假，讀者當得意忘言可也。

「大曰筮，筮曰遠，遠曰反」，王弼本以「逝」代「筮」，作「大曰逝，逝曰遠，遠曰反」。筮者，推演占度之義；逝者，往也，亦通。蓋道之為大，必有所往，往而後遠，遠而後返，周流不殆，終則有始。《易》曰「無平不陂，無往不復」，理在此矣。

王弼本作「域中有四大，而王居其一焉」；帛書作「國中有四大，而王居一焉」，義稍隘。域者無疆，國者有域，以道言之，域中為優。然四大之旨則一：道大，天大，地大，人亦大。王者，人之代表也，人能參天地之大，唯以王為代表。

「人法地，地法天，天法道，道法自然」，此四法之序也。人法地，取其厚德无私；地法天，取其覆載无私；天法道，取其不宰有功；道法自然，自然者非自然界，乃「自然而然」之自性——道之所以然者也。連道亦有所法，是自然者道之道也。此章之眼，於是乎在。

道之在天下，大矣遠矣，彌綸宇宙，而要歸自然。聖人知返，百姓日用而不知，學者苟會此循環之理，則道生天地之旨，思過半矣。
