第十八章 含德

原文

含德之厚者 比於赤子 逢𢔯𧍥地弗螫 擢鳥猛獸弗搏 骨弱筋柔而握固 未知牝牡之會而朘怒 精之至也 終曰號而不嚘 和之至也 和曰常 知和曰明 益生曰祥 心使氣曰強 物壯即老 胃之不道 不道蚤巳

對校

含德之厚，比於赤子。蜂蠆虺蛇不螫，猛獸不據，攫鳥不搏。 : 骨弱筋柔而握固。 : 未知牝牡之合而全作， : 精之至也。終日號而不嗄， : 和之至也。知和曰常， : 知常曰明。 : 益生曰祥。 : 心使氣曰強。 : 物壯則老，謂之不道，不道早已。

甲乙本校記

本章帛書原文據甲本，甲殘者（「含德之厚者」「未知牝牡之會而朘怒」「精之至也」及末二句）據乙本補；字從《集成》（2014）括號外原字。

  • 含德之厚者：甲本「含德」二字殘，據乙本補，「者」字《集成》直接釋出。王弼本作「含德之厚」，無「者」。
  • 逢𢔯𧍥地弗螫：從甲本。「逢」讀為「蜂」，「𢔯」（从彳从剌）讀為「蠆」，「𧍥」（从虫从畏）讀為「虺」，「地」讀為「蛇」。乙本作「蠭癘虫蛇弗赫」，其「癘」字，陳劍改釋為从「萬」（「蠆」之古字）之字，《集成》從之。王弼本作「蜂蠆虺蛇不螫」。（《集成》肆·頁201·注79）
  • 擢鳥猛獸弗搏：從甲本。「擢」字原釋文逕作「攫」，《集成》從高明改釋為「擢」。乙本作「據鳥孟獸弗捕」，以「孟」為「猛」，以「捕」為「搏」。王弼本分作二句：「猛獸不據，攫鳥不搏」。（《集成》肆·頁26·注96）
  • 骨弱筋柔而握固：從甲本；乙本作「骨筋弱柔而握固」，「筋」「弱」互倒。
  • 未知牝牡之會而朘怒：從乙本。甲本「牝牡」下二字原整理者據乙本補作「之會」，「而」下一字原釋為「朘」；陳劍於甲本行末綴上一殘片，「之」字清楚，其下一字殘存頭部，形與「會」「合」皆不合，「而」下一字亦難辨，《集成》皆改作□，末字仍補「怒」。王弼本作「未知牝牡之合而全作」。（《集成》肆·頁26·注98）
  • 精之至也：從乙本；甲本「之」字殘，句末有鉤識。
  • 終曰號而不嚘：從甲本。甲本「曰」為「日」之誤字，《集成》正作「曰〈日〉」；「嚘」字甲本原形作上山下发之字，《集成》讀為「嚘」（嗄）。乙本作「冬日號而不□」，「不」下一字原釋文據甲本寫定為「嚘」，《集成》以其僅「口」旁可辨而改作□。王弼本作「終日號而不嗄」。（《集成》肆·頁201·注80）
  • 和之至也：從甲本。乙本「至」字原補於下截，《集成》據襯頁所粘殘片於上截釋出，「也」字據反印文釋出。（《集成》肆·頁201·注81）
  • 和曰常：從甲本。乙本此句原整理者據傳本補作「知和曰常」；陳劍據襯頁反印文，「曰」上與上句「也」之間只容一字，文義只能是「和」，《集成》改釋為「□（和）曰常」，亦無「知」字。王弼本作「知和曰常」。（《集成》肆·頁27·注100；頁201·注82）
  • 知和曰明：從甲本；乙本作「知常曰眀」，王弼本作「知常曰明」。甲本此「和」字，原釋文以為「常」之誤字。（《集成》肆·頁27·注100）
  • 益生曰祥：甲乙同；乙本「曰」字原為補文，《集成》據反印文直接釋出。（《集成》肆·頁201·注83）
  • 物壯即老：從甲本，「物壯」二字原為補文，《集成》據新綴碎片直接釋出；乙本作「物壯則老」，「壯」字據反印文釋出。王弼本同乙本。（《集成》肆·頁27·注101；頁201·注84）
  • 胃之不道　不道蚤巳：從乙本，乙本「不」「道」下皆有重文號，讀作「胃之不道，不道蚤巳」；「蚤」讀為「早」，「巳」讀為「已」。甲本「道」下重文號及「早已」二字皆殘失，原釋文作補文；其「早」位原有一似「以」或「巳」之殘片，《集成》姑仍原釋。王弼本作「謂之不道，不道早已」。（《集成》肆·頁27·注101）

注疏

杳眇曰：

含德之厚，莫若赤子。非赤子之德厚，乃赤子之德全也。赤子無知無欲，純氣未漓，精充而神定，異物不相害，是德全之驗也。蜂蠆弗螫，猛獸弗搏，以其與物無忤，終日號哭而喉不嘶，以其神氣渾全。骨弱筋柔而握固，握固者精不外泄之象；未知牝牡之會而朘怒，朘怒者精充自然而無欲之徵。精全則氣全，氣全則聲不嘶。終日之號，和之至也。

帛書甲本言「和曰常，知和曰明」，王弼本易為「知和曰常，知常曰明」。乙本前句亦無「知」字，作「□曰常」，所闕一字以文義當為「和」；後句作「知常曰眀」，乃與王弼同。王弼之序多一「知常」中介，轉折稍繁；帛書之義更直：和即是常，知和即是明，無待而大明無蔽。此王弼與帛書字義之辨，不可不察也。

益生曰祥，祥者妖祥之兆。益生者於生之外加物，非不養，乃益之太過，反害其生之自然。今人好補益、營衛於外，皆益生之失。心使氣曰強，心志驅使血氣，是有為之逞強，非无為之和美。強者不和，物壯即老，不道之人早已。

是故德全在未鑿，未鑿在知和。聖人歸嬰，非使人退化為兒，乃教人勿以有為鑿其自然之性。去智巧，絕嗜欲，至虛極、守情表，使心無所染、氣無所乖，長生久視，復何老死之患哉。
