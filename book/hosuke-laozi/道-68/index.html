第六十八章 同道

原文

希言自然

飄風不冬朝 暴雨不冬日

孰為此 天地而弗能久 有兄於人乎 故從事而道者同於道 德者同於德 失者同於失

同於德者 道亦德之 同於失者道亦失之

對校

希言自然。 : 故飄風不終朝，驟雨不終日。孰為此者？天地。天地尚不能久，而況於人乎？ : 故從事於道者，道者同於道， : 德者同於德， : 失者同於失。 : 同於道者，道亦樂得之；同於德者，德亦樂得之；同於失者，失亦樂得之。 : 信不足焉，有不信焉。 :

甲乙本校記

本章帛書原文據甲本，甲殘之「天地而弗能久」「有兄於人乎」「同於德者」三句據乙本補；字從《集成》（2014）括號外原字。

  • 飄風不冬朝：從甲本，「冬」讀為「終」；乙本「飄」作上艹下剽之「𦾑」，讀為「飄」。王弼本作「故飄風不終朝」。
  • 暴雨不冬日：甲乙同；王弼本作「驟雨不終日」，「暴」作「驟」。
  • 孰為此　天地而弗能久：甲本「天地」下「而弗」二字殘；「能久」二字原釋文作補文，《集成》據陳劍新綴殘片直接釋出。今據乙本。王弼本作「孰為此者？天地。天地尚不能久」。（甲本第139行；《集成》肆·頁52·注92）
  • 有兄於人乎：甲本「又況」二字殘，據乙本；乙本「有」讀為「又」，「兄」讀為「況」。王弼本作「而況於人乎」。
  • 故從事而道者同於道：甲乙同；王弼本作「故從事於道者，道者同於道」，「而」作「於」，又疊「道者」二字。
  • 德者同於德：甲乙同。《集成》讀二「德」字為「得」，下文「道亦德之」之「德」亦然。
  • 失者同於失：從甲本。甲本句首「失」字抄手原誤寫作「者」，以硃塗去而改寫「失」，原釋文作「者〈失〉」；《集成》審照片，塗硃後所寫之「失」尚存痕跡，直接釋為「失」。乙本作「失」。（《集成》肆·頁52·注92）
  • 同於德者：甲本作「同德□」，無「於」字，「者」字殘，據乙本。王弼本作「同於道者，道亦樂得之；同於德者，德亦樂得之」，帛書二本皆無「同於道者」一句。
  • 同於失者道亦失之：甲乙同；甲本「失」字《集成》直接釋出。王弼本作「同於失者，失亦樂得之」，下有「信不足焉，有不信焉」二句，帛書二本皆無。

注疏

杳眇曰：

此章之要在明「合同」之理，而以風雨為喻，警乎多言有為之不可久也。

夫希言自然者，老子揭示治道之本。希言者，少言也，不言而民自化，聖人貴乎希言。言多則政苛，政苛則民擾。[[不爭之德]]、希言之旨，二義相成，皆歸无為之域矣。

風雨之喻，所謂「[[飄風不終朝]]，[[暴雨不終日]]」也（帛書「終」皆作「冬」，暴雨王弼作「驟雨」）。帛書云「孰為此，天地而弗能久」，正[[天地弗能久]]之旨也。王弼本增「者」字，又作「天地尚不能久」，辭氣稍緩而義則一貫。言天地以自然之威，猶不能令風雨持久，況人之有為，其能久乎？是以聖人循其自然之勢，不敢強民以所不堪也。

[[同道]]之旨，帛書與王弼本文字小異而義有大別。帛書云「故從事而道者同於道，德者同於德，失者同於失」，辭簡而義賅；王弼本多「道者」二字，辭複而意明。其下「同於德者，道亦德之」，帛書與王弼本尤為大異：王弼本作「同於道者，道亦樂得之；同於德者，德亦樂得之」，一氣貫下，義備三端；帛書則云「同於德者道亦德之，同於失者道亦失之」，闕「同於道者」一段，而辭義皆簡。愚以為帛書此文或有脫佚，然其「道亦德之」之語（《集成》讀此諸「德」字為「得」，則與王弼「樂得之」義近），如字讀之，直指道之不棄德、失之不渝，二義對舉，亦通。又，王弼本末有「信不足焉，有不信焉」二句，帛書闕之。此二句乃十七章之文，錯簡也，王弼本傳授之中或有竄入，然其義亦通，姑并存之。

合同之義，通於感應之自然。《文言》所言「同聲相應，同氣相求」，物理之必然也。[[各從其類]]，聖人知此，故希言无為，幾於道而觀水之善下悟不爭之旨，不以有涯隨無涯，而天下莫能與之爭。此道之所以長久也。
