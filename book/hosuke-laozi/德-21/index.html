第二十一章 為正

原文

亓正閔閔亓民屯屯亓正竊竊亓邦夬夬 𢢸福之所倚 福禍之所伏 孰知亓極 亓无正也 正復為奇 善復為 人之𢘻也 亓日固久矣 是以方而不割 兼而不刺直而不紲 光而不眺

對校

其政悶悶，其民淳淳； : 其政察察，其民缺缺。 : 禍兮福之所倚，福兮禍之所伏。孰知其極？其無正。 : 正復為奇， : 善復為妖。 : 人之迷，其日固久。 : 是以聖人方而不割， : 廉而不劌， : 直而不肆， : 光而不燿。 :

甲乙本校記

本章甲本「孰」字以下全殘，帛書原文首句甲乙相參，「𢢸福之所倚」「福禍之所伏」二句據甲本，「孰知亓極」以下皆據乙本；字從《集成》（2014）括號外原字。

  • 亓正閔閔亓民屯屯亓正竊竊亓邦夬夬：甲乙相參。甲本章首一句殘去，唯存後一小句末字之重文號；原整理者補作「其政閔閔，其邦屯屯」，《集成》據乙本、北大本改「邦」為「民」，並改原補之「屯屯」為「□﹦」，謂原文或作「屯」或「惷」。今「閔閔」「亓民屯屯」從乙本。「竊竊」從甲本，原釋文釋「察」，陳劍以殘字「宀」下兩重弧筆與「祭」形不合，改釋「竊」，讀為「察」；乙本作「察」。末句「亓邦夬夬」從甲本，「夬夬」讀為「缺缺」；乙本「亓」下殘，原補「民缺缺」，《集成》據北大本改補「國」。王弼本作「其政悶悶，其民淳淳；其政察察，其民缺缺」。（《集成》肆·頁29·注116；頁30—31·注117；頁202·注93）
  • 𢢸福之所倚　福禍之所伏：從甲本。甲本前一「禍」字作異體「𢢸」，後一「禍」字原釋文亦寫作同一異體，《集成》謂原文實為一般之「禍」，改正。乙本「福」字所在小殘片，原圖版位置過高，與「之所伏」間留一空位，原釋作「福，【禍】之所伏」；《集成》據反印文下移殘片，且殘片上尚存「禍」字殘畫，改釋為「禍，福之所伏」，疑乙本書「禍福」二字後誤接「之所伏」，脫去「之所倚福禍」五字。王弼本二句皆有「兮」字。（《集成》肆·頁31·注118；頁202·注94）
  • 孰知亓極：從乙本；甲本唯「孰」字《集成》直接釋出，其下文字在已全殘之兩行中。（《集成》肆·頁29·注116）
  • 亓无正也：從乙本，「亓」字原為補文，《集成》據襯頁反印文釋出。王弼本作「其無正」，無「也」。（《集成》肆·頁202·注95）
  • 正復為奇：從乙本，「復為奇」三字原為補文，《集成》據反印文直接釋出。（《集成》肆·頁202·注96）
  • 善復為：從乙本。原釋文於「為」下補「妖」字，《集成》據反印文，此處實無「妖」字之位，當為脫文。王弼本作「善復為妖」。（《集成》肆·頁202·注97）
  • 人之𢘻也：從乙本，「𢘻」讀為「迷」，「人」字原為補文，《集成》據反印文釋出。王弼本作「人之迷」，無「也」。（《集成》肆·頁202·注98）
  • 亓日固久矣：從乙本；王弼本無「矣」。
  • 是以方而不割：從乙本；王弼本作「是以聖人方而不割」，帛書無「聖人」二字。
  • 兼而不刺直而不紲：從乙本。「刺」字原釋文如此，《集成》從陳劍說以為釋「刺」與字形不合，改釋為「利」，讀為「劌」；陳劍又以為此字更可能是从刀末聲之字，亦讀「劌」。王弼本作「廉而不劌，直而不肆」。（《集成》肆·頁202·注99）
  • 光而不眺：從乙本；王弼本作「光而不燿」。

注疏

杳眇曰：

此章之要，在論政治寬猛之辨與禍福倚伏之理，而歸根於聖人方正之德。帛書、王弼二本之異，不可不察也。

夫「閔閔」與「悶悶」，皆寬簡之貌；「屯屯」與「淳淳」，皆厚實之貌。水之性柔，故能滋潤萬物而不爭；政治亦然，寬則民淳，猛則民缺。所謂「[[其政察察]]」者，峻法繁令、苛察之政也；无為而治者，法水之善利萬物而有靜，因民之自然而治之，此水善利萬物而有靜之旨也。

至若「[[兼而不刺]]」，帛書之文也；王弼本作「廉而不劌」。兼者，兼容並蓄之謂；廉者，廉隅方正之謂。兼者近道家之和，廉者近儒家之節。「兼而不刺」者，言聖人之量，廣而不侵也；「[[方而不割]]」者，方正而不傷物也；「[[光而不耀]]」者，聖德內含，不以明耀炫人也；「[[直而不紲]]」者，王弼本作「肆」，直道而行而不多暴於物也。

「亓无正也，正復為奇，善復為訞」（甲本盡殘；乙本如此，唯「訞」字原件所無，蓋抄手脫之，據文例補讀）——此即不爭故无尤之義也。夫人之有尤，由於爭；欲无尤者，必先去爭之心。此非相對主義，乃時變之觀——正善非恆質，乃隨時而變之位。禍福亦然，無絕對之禍，無絕對之福，所謂「𢢸，福之所倚；福，禍之所伏」，互為條件，如環無端。此乃物理如實之觀，非宿命之悲觀也。

「人之迷也，亓日固久矣」（乙本「迷」作「𢘻」，甲本殘）——人之迷執於禍福正邪久矣，老子不責之，但歎之。久迷難醒，故聖人不強醒人，乃以方不割、兼不刺、直不紲、光不耀自處。此四者皆有其體而斂其用——方者有邊而不以邊傷人，兼者能容而不以容制人，直者正而不以正暴人，光者明而不以明炫人。

考之[[德經]]之義，拘校上古中古下古大德之善言，以類相從而成。帛書無「聖人」二字，直云「是以方而不割」，其義彌深。蓋此方正之德，非聖人獨有，乃道之固然也。[[為而不爭]]，乃全德之終。不爭之心達於上下，則光而不耀之治成矣。
