第二十一章 為正

原文

亓正閔閔 亓民屯屯 亓正察察 亓邦夬夬 禍 福之所倚 福 禍之所伏 孰知亓極 亓无正也 正復為奇 善復為訞 人之迷也 亓日固久矣 是以方而不割 兼而不刺 直而不紲 光而不耀

對校

其政悶悶，其民淳淳； : 其政察察，其民缺缺。 : 禍兮福之所倚，福兮禍之所伏。孰知其極？其無正。 : 正復為奇， : 善復為妖。 : 人之迷，其日固久。 : 是以聖人方而不割， : 廉而不劌， : 直而不肆， : 光而不燿。 :

注疏

杳眇曰：

此章之要，在論政治寬猛之辨與禍福倚伏之理，而歸根於聖人方正之德。帛書、王弼二本之異，不可不察也。

夫「閔閔」與「悶悶」，皆寬簡之貌；「屯屯」與「淳淳」，皆厚實之貌。水之性柔，故能滋潤萬物而不爭；政治亦然，寬則民淳，猛則民缺。所謂「[[其政察察]]」者，峻法繁令、苛察之政也；无為而治者，法水之善利萬物而有靜，因民之自然而治之，此水善利萬物而有靜之旨也。

至若「[[兼而不刺]]」，帛書之文也；王弼本作「廉而不劌」。兼者，兼容並蓄之謂；廉者，廉隅方正之謂。兼者近道家之和，廉者近儒家之節。「兼而不刺」者，言聖人之量，廣而不侵也；「[[方而不割]]」者，方正而不傷物也；「[[光而不耀]]」者，聖德內含，不以明耀炫人也；「[[直而不紲]]」者，王弼本作「肆」，直道而行而不多暴於物也。

「亓无正也，正復為奇，善復為訞」——此即不爭故无尤之義也。夫人之有尤，由於爭；欲无尤者，必先去爭之心。此非相對主義，乃時變之觀——正善非恆質，乃隨時而變之位。禍福亦然，無絕對之禍，無絕對之福，所謂「禍，福之所倚；福，禍之所伏」，互為條件，如環無端。此乃物理如實之觀，非宿命之悲觀也。

「人之迷也，亓日固久矣」——人之迷執於禍福正邪久矣，老子不責之，但歎之。久迷難醒，故聖人不強醒人，乃以方不割、兼不刺、直不紲、光不耀自處。此四者皆有其體而斂其用——方者有邊而不以邊傷人，兼者能容而不以容制人，直者正而不以正暴人，光者明而不以明炫人。

考之[[德經]]之義，拘校上古中古下古大德之善言，以類相從而成。帛書無「聖人」二字，直云「是以方而不割」，其義彌深。蓋此方正之德，非聖人獨有，乃道之固然也。[[為而不爭]]，乃全德之終。不爭之心達於上下，則光而不耀之治成矣。

帛書甲本
