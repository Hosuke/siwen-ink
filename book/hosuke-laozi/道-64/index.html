第六十四章 食母

原文

絶學无憂唯與呵 其相去幾何 美與惡 其相去何若

人之所畏 亦不可以不畏人

朢呵亓未央才 眾人巸巸若鄉於大牢 而春登臺

我泊焉未兆 若嬰兒未咳 累呵 佁无所歸 眾人皆又余 我獨遺 我禺人之心也惷惷呵 鬻人昭昭 我獨若𨴽呵鬻人察察 我獨閩閩呵忽呵

亓若海朢呵 其若无所止 眾人皆有以 我獨門□以鄙 吾欲獨異於人 而貴食母

對校

絕學無憂，唯之與阿，相去幾何？善之與惡，相去若何？人之所畏，不可不畏。 : 荒兮其未央哉﹗ : 眾人熙熙，如享太牢，如春登臺。 : 我獨泊兮其未兆，如嬰兒之未孩； : 儽儽兮若無所歸。 : 眾人皆有餘，而我獨若遺。 : 我愚人之心也哉﹗ : 沌沌兮， : 俗人昭昭， : 我獨昏昏。俗人察察， : 我獨悶悶。澹兮其若海， : 飂兮若無止。 : 眾人皆有以， : 而我獨頑似鄙。 : 我獨異於人，而貴食母。 :

甲乙本校記

本章甲乙二本皆有殘損，甲本存者從甲本，甲殘者據乙本補；字從《集成》（2014）括號外原字。甲本道篇「其」字作「其」，乙本作「亓」。

  • 絶學无憂唯與呵：從乙本。甲本「絕學無」三字殘，「憂」字《集成》直接釋出；「呵」甲本作「訶」。王弼本「絕學無憂」為第二十章首句，下作「唯之與阿」。
  • 其相去幾何　美與惡　其相去何若：從甲本；乙本「其」作「亓」，「惡」作「亞」，讀為「惡」。王弼本作「相去幾何」「善之與惡」「相去若何」，帛書「美」字王弼本作「善」。
  • 人之所畏　亦不可以不畏人：甲本「所畏」二字原作補文，《集成》據第128、129行下部新綴碎片直接釋出；「亦不」以下甲本殘，據乙本。乙本句末「人」字，原注疑衍，《集成》以為非衍文，甲本補文亦加「人」。王弼本作「人之所畏，不可不畏」，義遂異。（《集成》肆·頁51·注75；頁209·注29）
  • 朢呵亓未央才：甲本殘，據乙本。「朢」讀為「恍」，「才」讀為「哉」。王弼本作「荒兮其未央哉」。
  • 眾人巸巸若鄉於大牢　而春登臺：從甲本，乙本同；「鄉」讀為「饗」。王弼本作「如享太牢，如春登臺」。
  • 我泊焉未兆：從甲本。原釋文作「佻（兆）」，《集成》以字左所从「人」形實為「兆」之一部分，暫釋「兆」。乙本作「我博焉未𠧞」，「博」讀為「泊」；「𠧞」作兩卜相背夾中豎之形，原釋文誤釋「挑」，《集成》從裘錫圭釋為「兆」。王弼本作「我獨泊兮其未兆」。（《集成》肆·頁51·注76；頁209·注30）
  • 若嬰兒未咳：甲本「嬰」字原作補文，《集成》據新綴殘片直接釋出；「兒未咳」三字殘，據乙本。王弼本作「如嬰兒之未孩」。（《集成》肆·頁51·注77）
  • 累呵　佁无所歸：「累呵」從甲本，乙本作「纍呵」。「佁无所歸」甲本作「如□□□」，據乙本；乙本「佁」讀為「似」，甲本作「如」。王弼本作「儽儽兮若無所歸」。
  • 眾人皆又余　我獨遺：「眾人皆又余」從乙本，甲本作「□□皆有餘」；「我獨遺」從甲本。乙本抄「我」字後誤跳接下句「愚人之心」，脫「獨遺我」三字，《集成》以脫文號標之。王弼本作「眾人皆有餘，而我獨若遺」。（《集成》肆·頁209·注31）
  • 我禺人之心也惷惷呵：從甲本，「禺」讀為「愚」；乙本作「我愚人之心也湷湷呵」。王弼本作「我愚人之心也哉！沌沌兮」。
  • 鬻人昭昭　我獨若𨴽呵鬻人察察：甲本此處殘，據乙本；甲本存「閩呵鬻人蔡蔡」。乙本「𨴽」，《集成》印本作門內从口从心之形，讀為「昏」；高明實錄作「閩」，圖版門中一豎上下貫通，形近虫旁，未能全定。王弼本作「俗人昭昭，我獨昏昏；俗人察察」。
  • 我獨閩閩呵忽呵　亓若海朢呵：「我獨閩閩呵忽呵」從甲本，「閩閩」讀為「閔閔」，乙本「忽」作「沕」；「亓若海朢呵」甲本「海」字殘，據乙本。王弼本作「我獨悶悶。澹兮其若海」。
  • 其若无所止：從甲本；乙本作「若无所止」，無「亓」字。王弼本作「飂兮若無止」。
  • 眾人皆有以　我獨門□以鄙：甲本「眾」與「人皆」原作補文，《集成》據陳劍新綴殘片直接釋出，下文殘，今從乙本。乙本「門」字原注以為涉上「閩閩」而誤之廢字，《集成》以其未經勾塗，作衍文處理；次字左半殘、右从元，讀為「頑」。高明實錄合為一字「閩」；圖版門、元二部各僅半字之高，或為一字，未能遽定。甲本作「□□□以悝」，「悝」讀為「俚」。王弼本作「而我獨頑似鄙」。（《集成》肆·頁51·注80；頁209·注35）
  • 吾欲獨異於人　而貴食母：甲乙同。甲本「吾」字，高明實錄作「我」，《集成》作「吾」。王弼本作「我獨異於人」，無「欲」字。

注疏

杳眇曰：

此章之要，在明道者之所以異於俗也。首言「唯與訶」「美與惡」，皆分別相也。唯者，應之善；訶者，應之慢。世人馳逐是非之場，於應對辭受之際，猶計較短長，此俗學之蔽也。[[帛書]]「人之所畏，亦不可以不畏人」，[[王弼本]]闕此文義。畏者，人之所同；能畏人者，道之所以通行也。《[[關尹子]]》云「道無人而[[聖人]]不見甲是道乙非道」，此則超越乎畏與被畏之上矣。

「朢呵，亓未央才」（乙本；才讀為哉，甲本殘），「[[荒兮其未央哉]]」之異文也。[[荒]]者廣大，朢者遠眺，皆言道之無際。道之充周，彌綸萬有，其廣無垠，其深無底，此之謂也。

「眾人巸巸，若鄉於大牢，而春登臺」，王弼本作「熙熙，如享太牢，如春登臺」。熙熙，示眾人欣然趨慕之貌。帛書「湷湷」，王弼本作「沌沌」。湷從水，喻道體渾淪若濁，義更深矣。「蔡蔡」與「[[察察]]」亦然，帛書別是一義，未可以今義強解。

「我泊焉未兆，若嬰兒未咳」，兆者朕跡，未兆者混沌無朕也。「我禺人之心也」，非真愚也，聖人智周萬物而自若愚闇，此[[大智若愚]]之旨也。鬻人[[昭昭]]，我獨若昏；鬻人蔡蔡，我獨悶悶。察察者苛細，悶悶者渾厚。聖人以渾厚勝，而不以察察自矜。

「忽呵，亓若海」，道體廣大無際之喻也。聖人之心，廓然無涯，若海之納百川而無不容也。

「眾人皆有以，我獨頑以悝」（「頑」字甲本殘；乙本作「門□」，「門」為衍文，次字左半殘、右从元，讀為頑），帛書作「以悝」，王弼本作「似鄙」。悝者諧也，頑者固執不化。帛書「以悝」義深，示聖人內省自修之意，較「似鄙」勝矣。

末云「吾欲獨異於人，而貴食母」，食母者，以道為母、取給於道也。帛書作「吾」，王弼本作「我」，吾字更近本真。《[[文子]]》云「聞而知之，聖也」，聖人聞道而行，故能[[幾於道]]而[[歸根復命]]。《[[大學]]》云「知止而後有定，定而後能靜」，泊焉未兆，正是知止之功；貴食母，正是能得之驗。

夫上善治水，水善利萬物而有靜，此幾於道之本也。所謂[[居善地]]，心善淵，與善仁，言善信，事善能，動善時，聖人法之，泊然无欲，歸根[[復命]]，故能若水之善利萬物而有靜。聖人无己，道无我，此其所以異於人，而實無異也。

要之，此章大旨，在明俗聖之分。俗人馳逐外物，昭昭察察，以有餘自矜；聖人歸根於內，湷湷昏昏，若無所用。世人逐外，修道者返本；世人貴物，聖人貴食母。此古今之通義，聖賢之微言也。學者茍能泊然无欲，歸根復命，則上善治水之德，可坐而致也。
