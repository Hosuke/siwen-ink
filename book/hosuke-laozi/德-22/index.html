第二十二章 長生

原文

治人事天 莫若嗇

夫唯嗇 是以蚤服 蚤服是謂重積德 重積德則无不克 无不克則莫知亓極 莫知亓極 可以有國 有國之母 可以長久

是謂深根固柢 長生久視之道也

對校

治人事天，莫若嗇。 : 夫唯嗇，是謂早服； : 早服謂之重積德； : 重積德則無不克，無不克則莫知其極； : 莫知其極，可以有國； : 有國之母，可以長久； : 是謂深根固柢，長生久視之道。

注疏

杳眇曰：

嗇之為德，微妙而用弘。[[河上公]]注云「嗇，愛也」，言治人者愛民如子，事天者法道之自然，二者皆以嗇為本。然嗇非吝嗇之謂，乃斂藏之義，愛其精神、嗇其智識之術也。嗇者藏之於內，節者省之於外；外之節有時而窮，內之嗇無時而盡。此二義之辨，不可不明。

帛書云「蚤服」，王弼本作「早服」。杳眇竊謂：蚤者跳也，先事而動之義；早者日居安思危之義。二字古每通用，然「蚤服」義長——言人能嗇則跳服乎道，不待困而後求也，非如「早」僅限於不遲而已。河上公注云「早，先也；服，得也」，是先得乎道之義，與《[[大學]]》「致知在格物」義相發明。

「重積德」者，非一事一功之積，乃源源不竭之蓄。嗇者蓄之，德者積之；蓄於內，積於無，故「重」非重複之謂，乃深沉之重。

「无不克，則莫知亓極」——帛書「亓」者，代詞指上文「无不克」之功；王弼改「亓」為「其」，義雖通而氣散。言敵者待相較而生，無可敵者無所相比，故其極不可知，此非誇大，乃內省之極境，克己者心無可制之敵，故无不克。

「有國之母」者，母者本也，道為立國之本。《文子》曰「聖人執沖含和，不下堂而行四海」，侯王以嗇守道，萬物自化，不必有為而天下正。嗇→蚤服→重積德→无不克→有國之母→長久，五級之序，由內而外，階級分明，如木之有根有柢。

末云「深根固柢，長生久視之道」——非追求不死，乃不自壞。深根者內力自全，固柢者外不能撼。如松柏之於霜雪，非不寒，乃寒不能入。若徒服藥而無神守，終不解矣。

夫嗇之為道，其用在今，其效在遠。世人知有為之利，不知無為之妙；知用力之功，不知惜神之道。嗇則精神不耗，微眇玄達，與道合真。《老子》曰「水善利萬物而有靜」，嗇亦若是，不爭而善勝，無為而無不為，含德之厚者所以比於赤子也。
