第三章 聞道

原文

上□□道 堇能行之 中士聞道 若存若亡 下士聞道 大芺之 弗芺□□以為道 是以建言有之曰 眀道如費 進道如退 夷道如類 上德如浴 大白如辱 廣德如不足 建德如揄 質□□□ 大方无禺 大器免成 大音希聲 天象无刑 道褱无名 夫唯道 善始且善成

對校

上士聞道，勤而行之； : 中士聞道，若存若亡；下士聞道，大笑之。不笑不足以為道。故建言有之﹕ : 明道若昧， : 進道若退， : 夷道若纇， : 上德若谷， : 大白若辱， : 廣德若不足， : 建德若偷， : 質真若渝， : 大方無隅， : 大器晚成， : 大音希聲， : 大象無形， : 道隱無名。夫唯道，善貸且成。 :

甲乙本校記

本章甲本所在之行幾全殘去，帛書原文全據乙本，乙本亦殘者存其闕；字從《集成》（2014）括號外原字。

  • 上□□道：甲本此章所在第9、10行全部殘去，原釋文按每行三十二字據乙本及傳本補足；《集成》除陳劍新綴跨行小殘片上之字外，皆改作☒，字數不可確知。殘片右行存从「辵」之字之「辵」旁，當即此句之「道」。乙本「上」下二字殘，王弼本作「上士聞道」。（《集成》肆·頁10·注23）
  • 堇能行之：乙本作「堇」，王弼本作「勤而行之」。
  • 大芺之　弗芺□□以為道：乙本二「芺」字，《集成》皆讀為「笑」；「弗芺」下二字殘。王弼本作「大笑之」「不笑不足以為道」。
  • 是以建言有之曰：從乙本。甲本新綴殘片左行存「之」「眀」二字，「之」即此句末字，據其位置，甲本「建言有之」下當無「曰」字；北大本亦無「曰」，郭店簡作「是以建言又之」。王弼本作「故建言有之」。（《集成》肆·頁10·注23）
  • 眀道如費：乙本作目旁之「眀」，讀為「明」；甲本唯存此句首字「眀」（新綴殘片）。王弼本作「明道若昧」；下文諸句乙本皆作「如」，王弼本皆作「若」。
  • 進道如退：乙本「退」字，《集成》印作彳旁之異構，讀為「退」。
  • 夷道如類　上德如浴：王弼本作「夷道若纇」「上德若谷」。
  • 建德如揄：「揄」字原釋文作缺文，據傳本補作「偷」；《集成》據襯頁反印文直接釋出「揄」，讀為「偷」。王弼本作「建德若偷」。（《集成》肆·頁198·注12）
  • 質□□□：乙本「質」下三字殘。末一字尚存右下二筆，為「俞」或「俞」旁之殘，原釋文補作「渝」，《集成》改作「□（渝）」。王弼本作「質真若渝」。（《集成》肆·頁198·注13）
  • 大方无禺　大器免成：王弼本作「大方無隅」「大器晚成」。
  • 天象无刑：「刑」讀為「形」；王弼本作「大象無形」。
  • 道褱无名：「道」下一字下半殘泐。原釋文作「褎」，以為「褎」之異構；《集成》從陳劍說，謂其字形實作「段」，秦漢段、殷相混，當視為「殷」之譌字，錄作「段〈殷〉」。圖版所存上半不足以定之，今姑存「褱」。王弼本作「道隱無名」。（《集成》肆·頁198·注16）
  • 夫唯道　善始且善成：從乙本。甲本第11行亦大半殘去，唯存「道」及其下「善」字之小殘片；《集成》保留原釋文所補「夫唯」「始且」，餘改作☒。王弼本作「夫唯道，善貸且成」。（《集成》肆·頁10·注24）

注疏

杳眇曰：

此章明聞道之三品，而以建言暢述上德之象。考帛書與王弼本之異，要者有六。

其一，「堇能行之」與「勤」。古「堇」通「勤」，然兼有「僅」義，上士行道僅能行之，艱難以為，非徒勤勉已也。其二，「眀道如費」與「若昧」。費者耗也，昧者暗也；昧猶明暗之對，費則明而似損，似損而實得，義更深矣。其三，「上德如浴」與「若谷」。浴兼洗滌之功，谷僅虛受之器。其四，「大器免成」與「晚成」最要者也。免成者不假施設，與上德无為之旨合；晚成猶在時間之內，免成已出時間之外。其五，「道褱无名」與「隱无名」。帛書此字下半殘泐，今存其形作「褱」；《集成》從陳劍說，以為「段」字，秦漢段、殷相混，當即「殷」之譌。殷者大也，道至大而無可名，義較隱藏更宏；或存其形，褱讀為懷，道懷萬有而不自名，義亦可通。二說未定，要皆以道之無名出於其大其富，非出於其隱也。其六，「善始且善成」與「善貸且成」。一貫始終，完密於施與之說。

上德之君，虛心任物，因應無方，功成事遂而不知誰之功，故無以為也。上士之所以聞道而行，正以知此諸「如」者，非故為眩惑，乃道之真相然也。

下士之笑、上士之行艱，亦若是矣。皆道之反象也。眀道如費，進道如退，夷道如類，建言諸「如」皆似反而實正。大方无禺、大音希聲、天象无刑，亦至極而反之道也。

夫道既反俗，俗之所笑，正其所以為道。帛書之「免」與「褱（殷）」，一字之易而道旨全殊。學者苟能於字句異同間，深察其義之深淺，庶乎可以讀老子矣。

帛書甲本
