第七十二章 恆德

原文

知其雄 守其雌 為天下溪 為天下溪 恒德不雞 恒德不雞 復歸嬰兒 知其日 守其辱 為天下浴 為天下浴 恆德乃足 恆德乃足 復歸於樸

知其 守其黑 為天下式 為天下式 恒德不貣 恒德不貣 復歸於无極 樸散則為器 𦔻人用則為官長 夫大制无割

對校

知其雄，守其雌，為天下谿。為天下谿，常德不離，復歸於嬰兒。 : 知其白，守其黑，為天下式。 : 為天下式，常德不忒， : 復歸於無極。 : 知其榮，守其辱，為天下谷，常德乃足，復歸於樸。 : 樸散則為器，聖人用之，則為官長， : 故大制不割。 :

甲乙本校記

本章大體據甲本；「恆德乃足」「復歸於樸」及末段「樸散則為器」「𦔻人用則為官長」二句甲本殘，據乙本補；字從《集成》（2014）括號外原字。甲本道篇作「其」，乙本作「亓」。

  • 章次：帛書甲乙皆以「知其雄」「知其白（日）守其辱」「知其白守其黑」為序，「守辱」一段居「守黑」之前；王弼本「守黑」在前，「守辱」在後，且作「知其榮，守其辱」。
  • 為天下溪：從甲本；乙本作「雞」，讀為「溪」。王弼本作「谿」。
  • 恒德不雞：從甲本。甲本「離」字錯寫作似「雞」非「雞」之字，《集成》摹其原形而讀為「離」；乙本作「离」。王弼本作「常德不離」。（《集成》肆·頁53·注111）
  • 甲本之重文號：甲本「恒德不雞」句德下漏書重文號，「為天下浴」句浴下脫重文號，二「恒」下亦無號；《集成》依寫者漏加處理，以〖﹦〗補之。今數據為存定文之讀，仍錄補足之號。（《集成》肆·頁53·注111、注113）
  • 復歸嬰兒：從甲本，無「於」字。乙本作「復歸【於嬰】兒」，其「歸」「兒」二字原釋文作補文，《集成》據上部殘筆直接釋出。王弼本作「復歸於嬰兒」。（《集成》肆·頁210·注45）
  • 知其日：從甲本。甲本字作「日」，彩版、黑白版皆扁框中一橫而上無撇，非殘損所致；高明實錄照錄作「日」，1980 釋文與《集成》徑釋為「白」。今錄原形，讀為「白」。乙本作「【知】亓白」，「知」字殘。王弼本作「知其榮」。
  • 為天下浴：從甲本；甲乙皆作「浴」，讀為「谷」。乙本「浴」上原誤抄「恆」字，已圈去作廢。王弼本作「為天下谷」。（《集成》肆·頁210·注46）
  • 恆德乃足　恆德乃足　復歸於樸：甲本唯存「恒德乃」，「足」及「復歸於樸」殘，據乙本。
  • 知其：從甲本。甲本「知其」下脫「白」字，乙本作「知亓白」，通行本同。（《集成》肆·頁53·注114）
  • 恒德不貣：甲乙同作「貣」，《集成》讀為「忒」；王弼本作「常德不忒」。
  • 樸散則為器：甲本作「楃散」，「楃」讀為「樸」，以下殘，據乙本。
  • 𦔻人用則為官長：甲本「聖」字殘，據乙本。乙本作⿰耳口之「𦔻」，讀為「聖」。王弼本作「聖人用之，則為官長」。
  • 夫大制无割：甲乙同；王弼本作「故大制不割」。

注疏

杳眇曰：此章以知守三對括聖人返本歸元之功，而其要在明无為之妙用。

夫雄與雌、白與辱、白與黑，皆相待之名也。世人知雄之可貴而慕之，知白之昭明而耀之。聖人則不然：知其雄而守其雌，知其白而守其辱，守其黑。守者不離之謂，不離者恆德之全也。

帛書與王弼本之異，學者不可不察。帛書作「知亓白守亓辱」（乙本如此，「知」字殘；甲本作「知其日守其辱」，「白」作「日」，筆畫完具而上無撇，蓋讀為「白」），王弼本作「知其榮守其辱」。榮者外炫也，辱者內含也。帛書作「白」，義尤深。白者，皎然未染之本真；守辱者，闇然自晦、甘受垢納也。以白守辱，是於昭明之本、守闇昧之用，於辯證之旨最為契合。河上公本經文亦云「守其黑，為天下式」，知白而守黑，正以其不自耀，故能為天下法。白之為白，乃本心之澄明，非外炫之光耀也；辱之為辱，乃斂藏之謙晦，非真垢汙也。知光而守垢，知明而守暗，此聖人无為之所以全德也。

又帛書作「為天下浴」，王弼本作「為天下谷」。此注取浴之洗濯義：聖人知白而守辱，如浴以自清其德，非徒受垢納汙而已。浴而後清，此恆德乃足之義也。

三復而歸不同：歸嬰兒者，嬰兒柔和，德性完具之初也。歸樸者，樸者未雕之木，返乎太初之渾沌也。歸无極者，无極者道之本體，空虛廣大，不可限量也。皆返本全真之功。

終之以「樸散則為器，𦔻人用則為官長，夫大制无割」。道之覆持萬有，如天地不言而四時行。散者，分也；割者，析也。无割者，不以有為之智巧分割天下也。《易》曰「無思也，無為也，寂然不動」，聖人體此，則樸散為器而不失其全，用之為官長而不傷其德，此之謂大制。

守黑淵默，返樸全真，聖人之於天下，無割而已。
