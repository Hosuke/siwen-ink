第八十一章 无名

原文

道恆无名

侯王若守之 萬物將自化 化而欲作 吾將貞之以无名之樸 貞之以无名之樸 夫將不辱

不辱以靜 天地將自正

對校

道常無為 : 而無不為。 : 侯王若能守之，萬物將自化。化而欲作，吾將鎮之以無名之樸。 : 無名之樸，夫亦將無欲。 : 不欲以靜，天下將自定。 :

注疏

杳眇曰：

道之於物，隱顯異名，體用殊途。帛書云「道恆无名」，王弼本易以「道常無為而無不為」。一從體言，一從用言，其旨一也。道恆无名者，道之質也，沖漠未朕，不可名號；而無為者，道之運也，化生萬物而功成不居。體用一原，顯隱異名，而道未嘗二。侯王若守此道，萬物將自化，此即「侯王若守之，萬物將自化」之義也。

然萬物自化之中，化而欲作者起焉。欲作者，嗜欲萌動，有為之漸也。吾將貞之以无名之樸。帛書乙本作「闐」，郭店作「貞」，王弼本作「鎮」。竊謂「貞」字義長，蓋貞者，正其所以不正，非外加之制也。「貞之以无名之樸」，言聖人治天下，不以智治，不以力勝，返百姓於無欲之樸，使自定焉。无名之樸非有術也，乃道之淳樸，足以正萬物之偏爾。化欲作之初而貞之於无名之樸，則欲不生，心不被累，[[不辱以靜]]，此自然而然之效也。

不辱以靜，天地將自正。帛書作「天地將自正」，王弼本作「天下將自定」。「請靚可以為天下正」，正者，各得其分、萬物自理之謂；又有「[[侯王得一以為天下正]]」之語，是知正者通天地人三才而言之，定者偏於治世之效爾。所謂「不彈而善勝」，言天道無為而萬物自歸其正。此章之義，歸乎一靜，靜之極，天地自正，无為之治至是備矣。學者讀此，當知無名之樸非有待於外求也，守之而已，守之則化欲不作，不辱而靜，天地自正矣。
