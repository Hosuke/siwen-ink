第七十四章 不強

原文

以道佐人主 不以兵強於天下 亓事好還 師之所居 楚棘生之 善者果而已矣 毋以取強焉 果而毋驕 果而勿矜 果而勿伐 果而毋得已居 是謂果而不強 物壯而老 是謂之不道 不道蚤已

對校

以道佐人主者，不以兵強天下。 : 其事好還。 : 師之所處，荊棘生焉。大軍之後，必有凶年。 : 善有果而已，不敢以取強。 : 果而勿矜，果而勿伐，果而勿驕。 : 果而不得已，果而勿強。 : 物壯則老，是謂不道，不道早已。 :

注疏

杳眇曰：

「[[以道佐人主]]」，道家之常談也。帛書云「不以兵強於天下」，王弼本脫「於」字，語氣小異。「於」字介詞，與「以兵強」相屬為文，輔君者當以道，不以兵，此老子之本旨也。

[[兵者不祥之器]]，聖人不得已而用之。用兵害人，必被害；用兵傷地，必被傷。此自然之報，非神明之罰也。「師之所居，楚棘生之」——言師行處則荊棘生，正[[兵凶戰危]]之實也。較之王弼本「荊棘生焉，大軍之後，必有凶年」，帛書不言凶年，義更渾全，蓋言其害及於地者深爾。

「善者果而已矣，毋以取強焉」——帛書作「善者」，多了「者」字，文氣舒展；又增語氣辭「矣」「焉」，較王弼本「善有果而已，不敢以取強」更見禁戒之嚴。「不敢」者，畏也；「毋以」者，禁也。禁之於未犯，其義深矣。果者，救急也，言聖人用兵，但求濟難，非欲逞強也。《[[易]]》曰「容民畜眾」，《[[論語]]》曰「遠人不服，則脩文德以來之」，未有恃兵而可以為治者。

「果而毋驕、果而勿矜、果而勿伐、果而毋得已居」——四者皆戒：驕者志意盈滿，矜者自恃其能，伐者揚己之功，得已居者貪戀不去也。末云「是謂果而不強」，合四者而一言之。善用兵者，取果而已；取果而四者皆戒，是之謂不強。

「物壯而老」——帛書作「而」，王弼本作「則」。一為轉語，示流轉之勢；一為定辭，示必然之理。「蚤已」之辨亦然：帛書作「蚤」，兼「早」與「早死」之義；「[[不道蚤已]]」者，非徒言其速亡，亦言其不齒於道也。強梁者死之徒，物壯即老，壯即衰之始，物理之常也。《[[南華真經]]》云「壽則多辱」，《[[列子]]》言「生可惜也，死亦可惜」，皆此意爾。

夫道恆无名，聖人取勝，非所欲也，不得已焉爾。功成而不居，是謂全德。《[[尚書]]·大禹謨》曰「汝惟不矜，天下莫與汝爭能；汝惟不伐，天下莫與汝爭功」，謙謙君子，萬民服之，儒道相須，其揆一也。是以聖人戰則濟，濟即退，退即忘，忘故不兆，不兆故無後患。逞強者亡，此之謂也。
